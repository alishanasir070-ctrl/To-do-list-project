**🌿 RoutineFlow — Daily Task & Routine Planner**

Organize your day, track completion metrics, and stay punctual with real-time alarms.

RoutineFlow is a lightweight, mobile-responsive web application designed to help you manage daily activities effortlessly. Featuring an intuitive soft-sage color palette, light/dark mode persistence, and real-time reminders.

## ✨ Features

* **⚡ Real-Time Alarm Reminders**: Audio and browser push notification alerts for scheduled tasks.
* **📊 Task Analytics**: Automatic tracking for Total, Completed, and Remaining tasks.
* **🌓 Dual Theme Engine**: Integrated Light/Dark mode with `localStorage` state persistence.
* **📱 Mobile-First Responsive Design**: Optimized touch targets and seamless layout scaling across all screen sizes.
* **🔒 Privacy-Focused**: 100% client-side execution — all your task data stays local to your browser.


* ## 🛠️ Built With

* **HTML5**: Semantic structure and accessible layouts.
* **CSS3**: Custom CSS variables, CSS grid/flexbox, and media queries.
* **JavaScript (ES6+)**: Local Storage API, Web Audio API, and Notification API.
